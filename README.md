## The joke

A smoke detector with a secret social life: it only ever beeps at 3 a.m., and the
twist is that it isn't warning anyone about a fire — it's just lonely and checking
I'm still alive.

## How it works

`main.py` writes one original funny line (under 200 characters, a single line, no
trailing newline) to `/output/entry.txt`, enforcing the bounty gate rules first
(1–200 characters, single line, not only whitespace) and verifying with a
read-back check that the file on disk is exactly the joke.

```sh
python3 main.py
```
